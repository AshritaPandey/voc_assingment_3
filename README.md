# 🚀 Premium Internships Platform

A stunning, responsive, and highly interactive landing page for internship programs. Built with modern web design principles, featuring dynamic content routing, glassmorphism UI, and premium micro-interactions.

## ✨ Features

- **Dynamic Details Page**: A single `details.html` template that dynamically populates content (titles, gradients, curriculum, icons) based on URL query parameters using Vanilla JavaScript.
- **Dark Mode Toggle**: A fully functional Light/Dark theme switch that saves user preferences to `localStorage`.
- **Interactive Spotlight Effect**: A custom JavaScript-driven radial gradient spotlight that tracks the user's cursor inside each card on hover.
- **Animated Backgrounds**: Smoothly floating, blurred background blobs that adapt to both light and dark themes.
- **Gradient Typography**: Shimmering, animated gradient text for the main headings.
- **Glassmorphism UI**: Semi-transparent, frosted-glass card backgrounds for a sleek aesthetic.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and accessible structuring.
- **CSS3**: CSS Grid/Flexbox layouts, Custom Properties (Variables), advanced `@keyframes` animations, and responsive media queries.
- **Vanilla JavaScript**: DOM manipulation, dynamic URL parameter parsing, mouse-tracking calculations, and state management.

## 📁 Project Structure

```text
Internships_Page/
│
├── index.html       # Main landing page with the 4 internship cards
├── style.css        # Core styles, animations, and dark mode variables
├── details.html     # Dynamic template page for individual program details
└── details.css      # Specific styling for the details view layout
```

## 🚀 Getting Started

Since this project is built entirely with static technologies (no backend or build tools required), running it locally is incredibly simple:

1. Clone or download the repository.
2. Double-click `index.html` to open it in any modern web browser.
3. Click on the "View Details" buttons or toggle the theme switch to explore the interactivity!

## 🌐 Hosting on GitHub Pages

This project is 100% ready to be deployed on GitHub Pages for free:

1. Create a new repository on GitHub and upload these files.
2. Go to your repository **Settings**.
3. Navigate to **Pages** on the left sidebar.
4. Under "Build and deployment", select the `main` branch and click **Save**.
5. Within a few minutes, GitHub will provide you with a live URL to share!
